## Implementation notes for Lovable

1. **Place this section** between "How it works" (existing) and the LeadQuik pricing cards.
2. **Reuse colors**: existing LeadQuik brand blue (#2563EB), emerald (#10B981) for ✓ checks, orange (#F97316) for the Founding-50 banner.
3. **Founding-50 counter**: query `count(*) from marketing_business_settings where features_enabled->>'founding_50_member' = 'true'` (you may need to add this flag on signup). Defaults to "12 spots claimed" if no real data yet.
4. **The "real example" story**: this is true (today's Cabinet Painting near-miss). It's specific, dated, dollar-quantified — keep it as written. Best converting copy comes from real incidents.
5. **Visual**: every dollar number deserves to POP (large + bold). Specific numbers convert better than ranges. If forced to pick one number, use the upper bound ("save up to $754/mo").
6. **Trust signal**: under each tier, add "Built and operated by the founder's own 4 home-services businesses. We use what we sell."
7. **Don't add testimonials yet** unless you have real ones. Honest "founder uses it" beats fake quotes every time.
8. **The 3-tier pricing block** can collapse on mobile to one tier at a time (carousel).
9. **Trial signup wiring**: clicking "Start free 14-day trial" creates a `marketing_business_settings` row with `service_tier='blaze_pro'`, `trial_ends_at = now() + interval '14 days'`. After 14 days a webhook auto-charges via Stripe (use existing LeadQuik Stripe wiring).
10. **Founding-50 logic**: first 50 trial-to-paid converts get `features_enabled.founding_50_member = true` permanently, which applies the 30% discount at every Stripe checkout.
